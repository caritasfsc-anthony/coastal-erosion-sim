# 長洲海岸侵蝕實驗室｜Cheung Chau Coastal Erosion Lab

一個以 **香港長洲** 為藍本、用 **Three.js** 製作的互動 3D 網上學習模擬。學生可以「快轉」數千年的海浪侵蝕與沉積，觀察岩岸與連島沙洲如何形成。介面全以繁體中文（香港）呈現。

> **教學模型聲明**：地形是簡化、可辨識的長洲輪廓（靈感來自 [地政總署 3D 地圖](https://3d.map.gov.hk/) 及實地參考圖），**並非精確測量／GIS 數據**，重點在地貌位置與形成過程。

## 可玩連結

https://caritasfsc-anthony.github.io/coastal-erosion-sim/

## 快速開始

```bash
cd coastal-erosion-sim
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

需要 Node.js 18+ 及支援 WebGL2 的瀏覽器。

| 模擬熱點 | 長洲對應（示意） |
| --- | --- |
| 連島沙洲 | 初期南北兩島分開 → 後期中央沙洲相連（啞鈴形） |

## 學習內容（9 個可點擊熱點）

海崖、浪蝕平台、海蝕隙、海蝕洞、海蝕拱、海蝕柱、海蝕殘柱（延伸）、海灘、連島沙洲。

## 功能

- **兩島 → 連島沙洲**：時間軸初期南北完全分開，中期水下沙洲，後期露出連接成啞鈴。
- **海浪方向**：指南針／滑桿即時改變浪向——邊岸浪花較多、沙洲／海灘偏向背浪側。
- **清潔岩岸教學外觀**：無植物、無建築物，突出岩石與沙。
- **真 3D 岬角／海蝕隙**：SDF + Surface Nets；浪拍打、浪蝕凹壁、崩塌碎石與浪擊點說明。
- **三種模式**：探索／故事／挑戰；另有「試吓轉浪向」提示與小任務。
- **侵蝕時間軸、潮汐、波浪能量**。
