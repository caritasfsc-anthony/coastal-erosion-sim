# 海岸侵蝕實驗室｜Coastal Erosion Lab

一個以 **Three.js** 製作的互動 3D 網上學習模擬，讓學生親手「快轉」數千年的海浪侵蝕，觀察岩岸地貌如何一步步形成。介面全以繁體中文（香港）呈現，地貌名稱附英文對照。

## 快速開始

```bash
cd /workspace/coastal-erosion-sim
npm install          # 首次執行
npm run dev          # 開發伺服器：http://localhost:5173（已綁定 0.0.0.0）
npm run build        # 型別檢查 + 打包到 dist/
npm run preview      # 預覽打包結果：http://localhost:4173
```

需要 Node.js 18+ 及支援 WebGL2 的瀏覽器（Chrome / Edge / Safari / Firefox 最新版）。所有地形均以程式即時生成，毋須下載任何模型或貼圖。

## 功能

- **真 3D 岬角**：岬角以有號距離場（SDF）＋ Surface Nets 即時建模，可以做出真正穿透的海蝕洞和海蝕拱；岬角分成數段由節理分隔的岩塊，依次經歷「洞 → 拱 → 柱 → 殘柱」，到後期由海向陸排成完整序列。
- **真 3D 海蝕隙**：海蝕隙同樣以 SDF ＋ Surface Nets 建模——沿一條垂直節理蝕出深而窄的裂隙，兩壁在水線被浪掏深、底部散落磨蝕用的巨礫，盡頭仍有未崩塌的海蝕洞及噴水洞；裂隙隨時間沿節理伸入陸地。浪湧入裂隙、撞向盡頭岩壁時水花上衝，噴水洞亦會噴出水柱。點選海蝕隙時，鏡頭會由海上高角度沿裂隙望入，並以發光線勾出裂隙邊緣、黃色流動虛線標示節理／斷層，附「浪沿弱點侵蝕擴大」等註解（挑戰模式自動隱藏）。
- **侵蝕時間軸**：拖動或播放時間軸（初期 → 中期 → 後期），海崖後退、浪蝕平台變闊、海蝕隙伸入陸地、海灘變闊、連島沙洲逐漸露出水面。幾何運算在 Web Worker 進行，拖動時畫面保持流暢。
- **海浪拍打 → 侵蝕**：浪花與每個浪頭同步爆開（水花沿崖面上衝、回落、留下海霧）；浪湧一下一下衝上浪蝕平台、拍向崖腳；浪花區岩石濕潤反光。侵蝕先在水線蝕出浪蝕凹壁，再把海蝕洞向內掏深、貫通成拱，拱頂崩塌時有塵土、落石與鏡頭震動；崖腳有落石被浪逐漸磨碎。播放時間軸或「觀看形成過程」時，會顯示閃動的「浪擊點」及說明卡（水力作用 · 磨蝕作用）。
- **三種模式**
  - 探索模式：自由旋轉／縮放，點擊熱點或左方清單，鏡頭自動飛到該地貌；若地貌尚未形成，會自動跳到合適階段。「▶ 觀看形成過程」會播放該地貌的形成動畫。
  - 故事模式：12 章逐步旁白，配合鏡頭與時間自動推進，可自動播放。
  - 挑戰模式：隨機 9 題，按描述在場景中點出正確地貌（隱藏標籤），即時回饋與計分。
- **互動工具**：自動旋轉、潮汐（中潮／低潮／高潮）、標籤開關、侵蝕作用面板、回到總覽；波浪能量滑桿（低／中／高・風暴）會改變浪高及浪花。
- **畫面**：Gerstner 波浪著色器、按水深變化的淺灘色彩、岸邊浪花與碎浪泡沫、岩石撞擊浪花粒子、黃昏漸層天空與雲、IBL 環境光、柔和陰影、Bloom、ACES 色調映射、玻璃質感 UI。
- **鍵盤**：空白鍵播放／暫停、← → 調整階段、Esc 關閉資料卡。

## 專案結構

```
src/
  main.ts          介面、模式、相機、主迴圈
  scene.ts         渲染器、燈光、天空、水面、後期處理
  world.ts         世界模型：所有地貌都是侵蝕階段 s∈[0,1] 的函數
  headlandCore.ts  岬角 SDF（洞、拱、柱、殘柱、崩塌碎石）
  surfaceNets.ts   等值面網格化
  terrainCore.ts   高度場地形（海崖、平台、海灘、島嶼、連島沙洲）
  geoCore.ts       海蝕隙 SDF（節理裂隙、浪蝕凹壁、巨礫、海蝕洞及噴水洞）
  geoGuide.ts      海蝕隙教學標示（裂隙輪廓、節理虛線、註解）
  buildWorker.ts   在 Web Worker 中重建幾何
  water.ts / sky.ts / splash.ts / vegetation.ts  視覺效果
  landforms.ts     地貌教學內容、出現條件與位置
  story.ts         故事模式章節
```
